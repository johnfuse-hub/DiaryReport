# 🌊 ระบบติดตามสถานการณ์น้ำและแจ้งเตือน LINE Messaging API
### (Water Situation Dashboard & Realtime LINE Alert System: C.46, C.7A, C.47)

โปรเจกต์ชุดการเรียนรู้และระบบปฏิบัติการติดตามสถานการณ์น้ำรายวัน สำหรับทีมงานในการฝึกสร้างแดชบอร์ด, การประเมินสถานะทางอุทกวิทยา (ปกติ / เฝ้าระวัง / เตือนภัยวิกฤต), และการส่งข้อความแจ้งเตือนอัตโนมัติผ่าน **LINE Messaging API (Flex Message)**

อ้างอิงข้อมูลและโครงสร้างเกณฑ์ระดับน้ำจาก: [Real time Hydro data | กรมชลประทาน - RID](https://hyd-app-db.rid.go.th/hydro5hd_admsl.html)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **📊 หน้าแดชบอร์ดติดตามสถานการณ์น้ำ (Interactive Dashboard)**
   - แสดงผลข้อมูล 3 สถานีหลัก:
     - **C.46**: อ.ท่าวังผา จ.น่าน (แม่น้ำน่าน)
     - **C.7A**: สะพานเอกาทศรถ อ.เมือง จ.พิษณุโลก (แม่น้ำน่าน)
     - **C.47**: สะพานบางแก้ว อ.บางมูลนาก จ.พิจิตร (แม่น้ำน่าน)
   - เกจวัดระดับน้ำเทียบระดับตลิ่ง (% Bankfull Level) แบบไดนามิก
   - สัญลักษณ์และสีสถานะ: 🟢 ปกติ | 🟡 เฝ้าระวัง | 🔴 เตือนภัย/วิกฤต

2. **🛠️ แผงจำลองสถานการณ์และปรับเกณฑ์ (Sandbox Simulator)**
   - ผู้ใช้สามารถเลื่อนปรับระดับน้ำปัจจุบัน (Slider / Input) เพื่อดูการเปลี่ยนแปลงสถานะแบบ Real-time
   - สามารถปรับเกณฑ์เฝ้าระวัง, เกณฑ์วิกฤต, และระดับตลิ่งได้เอง
   - มีปุ่มพรีเซ็ตสถานการณ์จำลอง: *สภาวะปกติ, สภาวะเฝ้าระวัง, สภาวะน้ำท่วมวิกฤต*
   - โหมดจำลองน้ำขึ้น-ลงอัตโนมัติ (Live Fluctuations)

## ⏰ ระบบตั้งเวลาแจ้งเตือน (ประหยัดโควต้า LINE วันละ 4 รอบ)
เพื่อประหยัดโควต้าข้อความฟรีของ LINE Messaging API ระบบถูกตั้งค่าให้ส่งสรุปสถานการณ์น้ำวันละ 4 ครั้ง:
* 🌅 **09:30 น.** (รอบเช้า)
* ☀️ **12:30 น.** (รอบเที่ยง)
* 🌤️ **15:30 น.** (รอบบ่าย)
* 🌆 **18:30 น.** (รอบเย็น)

### วิธีการรันระบบแจ้งเตือนอัตโนมัติ:
1. **ผ่าน GitHub Actions (บน Cloud ฟรี ไม่ต้องเปิดคอมพ์):**
   * ระบบตั้งเวลาด้วย Cron `30 2,5,8,11 * * *` (UTC) ซึ่งตรงกับ 09:30, 12:30, 15:30, 18:30 น. (เวลาไทย)
2. **ผ่านเครื่องคอมพิวเตอร์ (Local):**
   * ดับเบิ้ลคลิกไฟล์ **`run_schedule_4times.bat`** เพื่อรันบอทรอส่งอัตโนมัติตามรอบเวลา
   * หรือรันคำสั่งกำหนดเวลาเอง:
     ```bash
     python python/water_monitor.py --schedule --times "09:30,12:30,15:30,18:30"
     ```

## 📱 ทางเลือกการใช้งานแดชบอร์ด (Web Dashboard)
1. **HTML/JavaScript Dashboard:** ดับเบิ้ลคลิก `index.html` หรือ `start_dashboard.bat`
2. **Streamlit Python Dashboard:** พิมพ์คำสั่ง:
   ```bash
   streamlit run streamlit_app.py
   ```
   *(สามารถนำขึ้น Streamlit Community Cloud เชื่อมต่อกับ GitHub ได้ฟรี 100%)*

3. **📈 กราฟสถิติและการวิเคราะห์ (Statistical Charts)**
   - กราฟแนวโน้มระดับน้ำย้อนหลัง 7 วัน เทียบกับเส้นเกณฑ์เตือนภัยและระดับตลิ่ง
   - กราฟเปรียบเทียบระดับน้ำเทียบตลิ่งของทั้ง 3 สถานี
   - กราฟอัตราการระบายน้ำ (Flow Rate / Discharge Rate) เทียบกับความจุลำน้ำ

4. **💬 ห้องทดลอง LINE Messaging API & LINE Flex Message**
   - ตัวอย่างหน้าจอมือถือจำลอง (Phone Mockup) เรนเดอร์การ์ด **LINE Flex Message** สวยงามตามมาตรฐาน
   - มีช่องกรอก Channel Access Token และ User ID เพื่อทดสอบยิงเข้า LINE จริงได้ทันที
   - ตัวดูโครงสร้าง JSON Payload และปุ่มคัดลอกสำหรับนำไปใช้กับ LINE Flex Message Simulator

5. **🤖 ระบบแจ้งเตือนอัตโนมัติผ่าน Python & GitHub Actions**
   - สคริปต์ Python สำหรับตรวจสอบและประมวลผลข้อมูล
   - ไฟล์ GitHub Actions Workflow รันแจ้งเตือนอัตโนมัติฟรีตามรอบเวลา (07:00 น. และ 18:00 น.)

## 🚀 เริ่มต้นใช้งานด่วน (Quick Start)

### 1. เปิดใช้งานทันทีบนคอมพิวเตอร์ (Localhost)
* **วิธีที่ 1 (สะดวกที่สุด):** ดับเบิ้ลคลิกไฟล์ **`start_dashboard.bat`** (ระบบจะดึงข้อมูลสดจาก RID และเปิดหน้าเว็บให้ทันที)
* **วิธีที่ 2:** ดับเบิ้ลคลิกไฟล์ **`index.html`** เพื่อเปิดดูหน้าแดชบอร์ดได้ทันที
* **วิธีที่ 3 (รัน Local Web Server):** ดับเบิ้ลคลิกไฟล์ **`run_local_server.bat`** หรือพิมพ์:
  ```bash
  python -m http.server 8000
  ```
  เปิดเบราว์เซอร์ไปที่: `http://localhost:8000`

### 2. ทดสอบส่งข้อความเข้า LINE
1. อ่านขั้นตอนการขอ Token ได้ที่ [LINE_SETUP_GUIDE.md](file:///c:/Users/admin/OneDrive/Desktop/Job/DiaryReport/LINE_SETUP_GUIDE.md)
2. นำ **Channel Access Token** และ **User ID** มาใส่ในหน้าเว็บแดชบอร์ด
3. เลื่อนปรับระดับน้ำให้เข้าสู่สถานะวิกฤต แล้วคลิกปุ่ม **"🚀 ส่งข้อความทดสอบเข้า LINE"**

### 3. นำขึ้น GitHub ให้ทีมงานใช้งาน
อ่านคู่มือฉบับเต็มได้ที่ [DEPLOY_GITHUB_GUIDE.md](file:///c:/Users/admin/OneDrive/Desktop/Job/DiaryReport/DEPLOY_GITHUB_GUIDE.md)
สามารถเปิดใช้ **GitHub Pages** เป็นโฮสติ้งฟรีให้ทีมงานเข้าดูผ่านมือถือได้ 24 ชั่วโมง
